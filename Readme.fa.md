## 🆕 تازه‌های نسخه v3.1.0

- **🔔 تلگرام حالا صفحه‌ی مستقل خودش را دارد** — توکن، شناسه چت و یک **پروکسی SOCKS5** اختیاری، زیر آیتم **تلگرام** در سایدبار جدا شده‌اند، نه توی تنظیمات. پروکسی برای این است که `api.telegram.org` از ایران فیلتر است: یک پروکسی SOCKS5 بده و تمام تماس‌های ربات با تلگرام (حتی DNS) از همان مسیر می‌رود. یک دکمه‌ی **ارسال پیام تست** هم هست تا قبل از اعتماد به تنظیمات، مطمئن شوی کار می‌کند. راه‌اندازی:
  1. به [@BotFather](https://t.me/BotFather) در تلگرام پیام بده، `/newbot` بفرست و توکن بات را کپی کن.
  2. یک پیام به بات جدیدت بفرست، بعد آدرس `https://api.telegram.org/bot<TOKEN>/getUpdates` را در مرورگر باز کن و مقدار `chat.id` را کپی کن — همین شناسه چت توست.
  3. هر دو را در صفحه‌ی **تلگرام** وارد کن. اگر تلگرام مستقیم از سرورت در دسترس نیست، میزبان/پورت یک پروکسی SOCKS5 هم بده. ذخیره کن، بعد **ارسال پیام تست** را بزن.
- **🔒 HTTPS + تغییر پورت از تنظیمات** — یک کارت جدید «شبکه پنل / HTTPS» به تو اجازه می‌دهد گواهی TLS و کلید خصوصی را پیست کنی یا فقط پورت را عوض کنی. این جفت **قبل از** نوشته‌شدن یا ری‌استارت پنل با `ssl.SSLContext.load_cert_chain` اعتبارسنجی می‌شود، پس یک گواهی نامعتبر یا ناهماهنگ نمی‌تواند پنل را از کار بیندازد. ذخیره کردن، پنل را خودکار ری‌استارت می‌کند.
- **🔐 هش رمز عبور با bcrypt** — رمزها دیگر با SHA-256 بدون salt ذخیره نمی‌شوند. **مهاجرت خودکار است**: اولین باری که بعد از آپدیت وارد می‌شوید، رمز فعلی‌تان بی‌سروصدا با bcrypt دوباره هش و ذخیره می‌شود — نیازی به هیچ کاری نیست.
- **📊 تاریخچه ترافیک هفتگی** — یک نمودار جدید در داشبورد، سرعت دانلود/آپلود هفت روز اخیر را نشان می‌دهد؛ هر ۶۰ ثانیه یک نمونه در یک دیتابیس SQLite محلی (`data/traffic.db`) ذخیره می‌شود.
- **🔔 هشدار تلگرام** — همان لحظه‌ای که یک نود آفلاین شود، پیام دریافت می‌کنید (راه‌اندازی بالا).
- **📱 چیدمان واکنش‌گرا برای موبایل** — سایدبار زیر ۷۶۸ پیکسل پشت یک دکمه همبرگری جمع می‌شود و کارت‌های داشبورد، بخش‌های دوستونه، و شبکه‌ی نودها روی صفحه‌ی موبایل تک‌ستونه می‌شوند.

## 🚀 نصب سریع

این دستور را روی سرور خود به عنوان **root** اجرا کنید:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/eris4444/packet-tunnel/main/install.sh)
```

اولین قدم نصب، نام کاربری و رمز عبور دلخواهت را می‌پرسد؛ بقیه‌ی مراحل بدون توقف اجرا می‌شوند. در پایان چیزی شبیه این می‌بینی:

```
╔══════════════════════════════════════════════════════════════╗
║         ✅  نصب با موفقیت انجام شد!                         ║
╚══════════════════════════════════════════════════════════════╝

  📌 اطلاعات دسترسی به پنل
  ┌──────────────────────────────────────────────────────────┐
  │  آدرس         : http://<IP-شما>:7777                    │
  │  نام کاربری   : admin                                   │
  │  رمز عبور     : (همانی که انتخاب کردی)                  │
  └──────────────────────────────────────────────────────────┘
```

> **نصب بدون تعامل** (بدون پرسش): `PANEL_USERNAME=admin PANEL_PASSWORD=yourpassword bash install.sh` — اگر اصلاً ترمینال تعاملی نباشد، یک رمز تصادفی ساخته و فقط یک‌بار نمایش داده می‌شود.

> **توجه:** رمز عبور به صورت تصادفی در زمان نصب ساخته می‌شود. فوراً آن را ذخیره کنید.

## 🗂 ساختار فایل‌ها

همه فایل‌های سورس **بدون زیرپوشه** در ریشه ریپازیتوری قرار دارند:

```
packet-tunnel/
├── install.sh           ← اسکریپت نصب با یک دستور
├── app.py               ← بک‌اند Flask (template_folder = همین دایرکتوری)
├── requirements.txt     ← flask · pyyaml · gunicorn · bcrypt · requests · PySocks · bcrypt
├── base.html            ← قالب مشترک: سایدبار + هدر
├── login.html
├── dashboard.html
├── services.html
├── service_detail.html
├── add_server.html
├── add_client.html
├── settings.html
├── nodes.html            ← رابط نظارت بر نودها
├── telegram.html         ← تنظیمات هشدار تلگرام و پروکسی SOCKS5
├── README.md            ← نسخه انگلیسی
└── README.fa.md         ← همین فایل (فارسی)
```

بعد از نصب، فایل‌های پنل در `/opt/paqet-panel/` کپی می‌شوند. یک زیرپوشه‌ی `data/` هم در زمان اجرا برای دیتابیس تاریخچه ترافیک ساخته می‌شود — بخشی از باندل نصب نیست:

```
/opt/paqet-panel/         ← فایل‌های پنل (flat)
└── data/
    └── traffic.db         ← تاریخچه ترافیک ۷ روزه (در زمان اجرا ساخته می‌شود)
/etc/paqet-panel/
├── config.json           ← اعتبارنامه، تنظیمات تم/زبان، توکن نود، تنظیمات تلگرام
└── nodes.json             ← نودهایی که این پنل به‌عنوان هاب زیر نظر دارد
/etc/paqet/
└── <نام>.yaml            ← پیکربندی‌های تانل
/etc/systemd/system/
├── paqet-panel.service   ← سرویس پنل وب
└── paqet-<نام>.service   ← سرویس‌های تانل
```

## ⚙️ نحوه کار

```
مرورگر  ──────►  gunicorn (0.0.0.0:7777)
                      │
                   app.py (Flask)
                      │
          ┌───────────┼───────────────┐
          │           │               │
     /etc/paqet/   systemctl      journalctl
      *.yaml       start/stop       لاگ‌ها
                   restart
```

- **Flask** همه صفحات HTML را از همان دایرکتوری flat سرو می‌کند (`template_folder='.'`)
- **systemd** یک اسکریپت کوچک به نام `start.sh` را اجرا می‌کند که قبل از بالا آوردن **gunicorn** (۲ worker)، پورت و تنظیمات HTTPS را از `config.json` می‌خواند — یعنی تغییر پورت یا HTTPS از تنظیمات، با ری‌استارت بعدی اعمال می‌شود، بدون دست‌زدن به سرویس systemd
- **systemd** هم سرویس پنل و هم همه سرویس‌های تانل را مدیریت می‌کند
- **اعتبارنامه‌ها** با bcrypt هش و در `/etc/paqet-panel/config.json` ذخیره می‌شوند

## 🛠 دستورات سرویس

```bash
# وضعیت پنل
systemctl status paqet-panel

# ری‌استارت پنل
systemctl restart paqet-panel

# لاگ زنده پنل
journalctl -u paqet-panel -f

# توقف پنل
systemctl stop paqet-panel
```

## 🗝 اطلاعات ورود

اسکریپت نصب هنگام راه‌اندازی از شما نام کاربری و رمز عبور دلخواه می‌پرسد (مرحله «اطلاعات ورود پنل») — چیزی به‌صورت خودکار تولید نمی‌شود، مگر اینکه نصب بدون ترمینال تعاملی انجام شود که در آن صورت یک رمز تصادفی ساخته و فقط یک‌بار نمایش داده می‌شود.

برای نصب اسکریپتی بدون پرسش:
```bash
PANEL_USERNAME=admin PANEL_PASSWORD=yourpassword bash install.sh
```

هر دو را بعداً از **تنظیمات ← امنیت** داخل پنل می‌توانید تغییر دهید.

## 🧩 راهنمای سریع تانل

### سرور (خارج — نقطه پایانی VPN)

در پنل **افزودن سرور** را باز کنید و پر کنید:

- **نام سرویس** — هر شناسه‌ای دلخواه (مثلاً `kharej1`)
- **پورت Listening** — پورتی که Paqet روی آن منتظر اتصال می‌ماند (مثلاً `8888`)
- **کلید مخفی** — به صورت خودکار تولید می‌شود؛ آن را برای کلاینت کپی کنید
- **مد KCP** — برای اکثر تنظیمات `fast` توصیه می‌شود
- **رمزنگاری** — `aes-128-gcm` توصیه می‌شود

### کلاینت (ایران — نقطه ورودی داخلی)

**افزودن کلاینت** را باز کنید و پر کنید:

- **آی‌پی سرور خارجی** — آی‌پی عمومی سرور بالا
- **پورت سرور** — همان پورتی که روی سرور تنظیم کردید
- **کلید مخفی** — کلیدی که از سرور کپی کردید
- **نوع ترافیک** — فوروارد پورت (برای V2Ray / Xray) یا پروکسی SOCKS5
- **پورت‌های فوروارد** — پورت‌ها با کاما جدا شده، مثلاً `443,80,8443`

## ⚠️ نکته مهم

مطمئن شوید هیچ پورت فوروارد شده‌ای با پورت تانل (پورت سرور) یکی نباشد؛ این کار باعث حلقه ترافیکی می‌شود و پهنای باند را می‌بلعد. پورت‌های فوروارد باید به سرویس‌های واقعی مثل V2Ray یا Xray اشاره کنند.
